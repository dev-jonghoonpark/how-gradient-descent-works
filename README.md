# 경사 하강법 — 지그재그(진동)를 중심으로

경사 하강법(Gradient Descent)에서 나타나는 지그재그 진동 현상을 인터랙티브하게 살펴보는 단일 페이지 문서입니다.
GD / Momentum / Adam 등의 동작 차이와 학습률, 조건수(condition number)에 따른 수렴·발산 양상을 시각화합니다.
